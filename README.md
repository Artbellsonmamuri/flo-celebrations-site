# FLO. — A little taste of celebration

A clean, responsive business website for FLO. in San Nicolas, Ilocos Norte. It presents FLO.'s welcome spreads, the Vibe Bar, party carts, and holiday styling, with a gallery of work from [FLO.'s Instagram](https://www.instagram.com/_flo.in/) and event inquiries.

**Live site:** https://flo-celebrations.right-cow-0993.chatgpt.site

## Run locally

Serve this repository's root directory with any static HTTP server, then open its local URL. No build step or external JavaScript packages are needed. For example:

```sh
python3 -m http.server 4173
```

The inquiry form prepares a message for the visitor to send by SMS or Facebook Messenger. It does not store or send visitor information itself. Since FLO.'s public profiles did not list package prices, the site asks visitors to inquire directly.

## Sources

- [Facebook](https://www.facebook.com/profile.php?id=100088341009431): FLO.'s service description, public phone number, and location.
- [Instagram](https://www.instagram.com/_flo.in/): FLO.'s portfolio photography.

The gallery uses photos from FLO.'s public Instagram posts. Its captions describe the photos for this website and are not official event titles. The site has no invented prices, testimonials, client roster, or service guarantees.

The live site is hosted with Sites. This repository is a source mirror; editing it does not automatically update the live site.
